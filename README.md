# 오르페우스 정기연주회 웹페이지 수정 가이드

이 문서에서는 웹페이지의 사진과 텍스트(글) 내용을 쉽게 수정하는 방법을 안내합니다.

---

## 1. 사진(이미지) 수정하는 방법

웹페이지에 들어가는 주요 사진들은 각 코드 파일 내에 `// TODO: [사진 변경]` 이라는 주석으로 표시되어 있습니다.
사용하시는 코드 에디터(VS Code 등)의 **전체 검색 기능(Ctrl + Shift + F)**을 활용하여 `[사진 변경]` 키워드를 검색하시면 교체해야 할 위치를 한 번에 찾을 수 있습니다.

기존에 적혀있는 `'https://images.unsplash.com/...'` 형태의 이미지 링크 주소를 지우고, 원하시는 이미지의 URL 링크로 교체하시면 됩니다.

### 📌 파일별 사진 수정 위치

1. **연주자 프로필 및 갤러리 메인 슬라이드 사진**
   - 파일 경로: `src/data/concertData.ts`
   - 수정 방법: 각 연주자의 `avatar` 속성과 갤러리 이미지의 `url` 속성에 적힌 링크를 변경하세요.

2. **메인 화면 포스터 배경 사진**
   - 파일 경로: `src/components/HeroPoster.tsx`
   - 수정 방법: `<img>` 태그의 `src="..."` 속성에 적힌 링크를 변경하세요.

3. **오시는 길 지도 이미지**
   - 파일 경로: `src/components/LocationSection.tsx`
   - 수정 방법: `<img>` 태그의 `src="..."` 속성에 적힌 링크를 변경하세요.

4. **팜플렛 다운로드 창의 표지 사진**
   - 파일 경로: `src/components/PamphletDownload.tsx`
   - 수정 방법: `<img>` 태그의 `src="..."` 속성에 적힌 링크를 변경하세요.

5. **갤러리 하단 2x2 콜라주(작은 사진들)**
   - 파일 경로: `src/components/GallerySection.tsx`
   - 수정 방법: 총 4개의 작은 사진을 나타내는 `<img>` 태그들의 `src="..."` 속성에 적힌 링크를 변경하세요.

---

## 2. 텍스트(글) 수정하는 방법

웹페이지 내의 인사말, 공연 안내, 곡 설명 등 텍스트 데이터는 모두 **`src/data/concertData.ts`** 파일 한 곳에 모여 있어 쉽게 수정이 가능합니다.
`src/data/concertData.ts` 파일을 열어 다음 항목들을 찾아 수정해 주세요.

### 📌 연주회 기본 정보 및 초대의 글 변경
파일 상단의 `CONCERT_INFO` 부분을 찾습니다.
* `title`, `subtitle`: 연주회 제목
* `date`, `venue`: 날짜 및 장소
* `invitationText`: 초대의 글 내용 (인사말)
* 큰따옴표(`'`) 또는 작은따옴표(`"`) 안의 글자를 원하시는 내용으로 덮어쓰시면 됩니다.

### 📌 연주자 프로필 글 변경
파일의 `ARTISTS` 부분을 찾습니다.
* 지휘자 및 각 단원들의 `name`(이름), `role`(역할), `bio`(소개글) 등을 수정할 수 있습니다.

### 📌 프로그램(연주곡) 해설 글 변경
파일의 `PROGRAM_PARTS` 부분을 찾습니다.
* 각 연주곡 데이터 내의 `description` 속성을 찾아서 곡 해설 내용을 수정하세요.
* `title`(곡 제목), `composer`(작곡가), `duration`(연주 시간) 등도 함께 변경할 수 있습니다.

### 📌 갤러리 사진 설명 및 방명록 내용 변경
* **갤러리 설명**: `GALLERY_ITEMS` 부분에서 각 사진의 `title`(제목)과 `caption`(사진 아래 설명글)을 수정하세요.
* **초기 방명록**: `INITIAL_GUESTBOOK` 부분에서 방명록 샘플 작성자 이름(`author`)과 내용(`message`)을 원하시는 내용으로 수정하세요.
